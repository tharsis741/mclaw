# 语音输入

## 功能设计

语音输入使用 Qwen Realtime ASR，将麦克风 PCM 音频实时转写为 M-Claw 输入。系统支持唤醒词和按键说话两种模式，并包含静音检测、重复转写过滤和服务端 VAD。

## 唤醒词模式

```text
/asr-mode wake_word
```

默认唤醒词为“小爪”和“老麦”。先说唤醒词，再说任务。未明确指定模式时：

```text
/asr-mode
```

会使用当前配置中的监听模式。

## 按键说话

```text
/asr-mode push_to_talk
```

默认按键为 `F8`，行为为单击开始、再次单击停止。实际按键标签会显示在 `/help` 和 ASR 启动提示中。

## 状态和退出

```text
/asr-status
/keyboard-mode
```

`/asr-status` 显示配置、监听模式和服务状态；`/keyboard-mode` 停止录音并恢复键盘输入。

## 配置要求

默认后端为 `qwen_realtime`，模型为 `qwen3-asr-flash-realtime`，需要授权 DashScope 凭据。默认语言为中文、采样率 16000 Hz、单声道 PCM。

Windows/Linux 桌面通常使用 `sounddevice`；Kaihong 环境可以使用 `arecord` 并自动处理 ALSA 配置。麦克风被其他进程占用时，诊断会尝试给出占用进程信息。

出于控制安全考虑，默认 `allow_voice_slash_commands` 为关闭状态，语音转写不会直接执行 Slash Command。
