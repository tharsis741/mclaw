# 语音输入

M-Claw 支持两种语音输入：

- 在微信、钉钉中发送语音消息。
- 使用电脑麦克风说话。

## 首次配置

运行：

```powershell
mclaw setup
```

在“M-Claw 语音输入”页面按需要选择：

- **IM 语音消息识别**：识别微信、钉钉语音消息。
- **麦克风实时语音**：使用本机麦克风输入。

按提示配置 Qwen/DashScope 凭据。若 M-Claw 正在运行，配置完成后请重启。

## 微信和钉钉语音

配置完成后，直接在与 M-Claw 的聊天中发送语音消息即可。M-Claw 会识别语音内容并正常回复。

使用时请注意：

- 请发送聊天中的原生语音消息；以普通文件形式上传的音频不会自动识别。
- 单条语音默认不超过 120 秒、7 MiB，较长内容请分段发送。
- `/new`、`/stop` 等命令需要使用文字发送。
- 语音会发送至配置的 Qwen 服务进行识别。

识别失败时，可重新发送较短的语音，或改用文字输入。

## 麦克风输入

### 唤醒词模式

```text
/asr-mode wake_word
```

默认唤醒词为“小爪”和“老麦”。先说唤醒词，再说任务。

### 按键说话

```text
/asr-mode push_to_talk
```

默认按 `F8` 开始说话，再按一次结束。

### 查看状态或退出

```text
/asr-status
/keyboard-mode
```

- `/asr-status`：查看语音配置和运行状态。
- `/keyboard-mode`：停止麦克风监听，恢复键盘输入。

## 常见问题

- 提示“语音识别尚未配置”：重新运行 `mclaw setup` 并选择对应语音功能。
- 微信或钉钉语音识别失败：缩短语音后重试，或更新 M-Claw 后重新启动。
- 麦克风没有声音：关闭可能占用麦克风的其他程序，然后重新启用语音模式。
- 仍无法使用：运行 `mclaw doctor` 查看诊断结果。
