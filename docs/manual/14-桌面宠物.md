# 桌面宠物

## 功能设计

桌面宠物是独立 Qt Sidecar，通过事件队列接收 Agent 状态。它可以展示空闲、运行、审查、等待、完成和失败状态，并通过气泡提示任务、工具、后台审查或委派结果。

## 基础控制

```text
/pet
/pet status
/pet on
/pet off
/pet restart
/pet save
```

`/pet` 默认显示状态。`save` 将当前宠物配置持久化。

## 外观和位置

```text
/pet scale <数字>
/pet position <bottom_right|bottom_left|top_right|top_left>
/pet position reset
/pet asset <名称或路径>
```

缩放值会限制在 `0.25` 到 `4.0`。宠物支持拖动并记忆位置；`position reset` 清除位置记忆，重启后生效。内置资源包括 `robot-dark` 和 `robot`。

## 气泡与通知

```text
/pet bubble on
/pet bubble off
/pet notify <turn|background|delegation|tool> <on|off>
```

默认开启回合完成、后台审查完成和委派完成通知，工具完成通知默认关闭。

## 测试

```text
/pet test
/pet test <事件名称>
```

测试命令向 Sidecar 发送模拟事件，用于检查动画和气泡。

桌面宠物依赖 PySide6 和图形桌面。Kaihong Runtime 当前禁用该功能；无图形环境的 Linux 也可能无法启动。
