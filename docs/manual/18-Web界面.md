# Web 界面

M-Claw 提供网页和终端两种交互方式，共用本机后台、配置、技能和会话历史。Web UI 面向 Windows、Kaihong OS 和 M-Robots OS。

## 安装与启动

从源码安装后，在仓库根目录构建前端。构建环境需要 Node.js 22.12+ 和 npm 10+：

```sh
npm --prefix webui ci
npm --prefix webui run build
mclaw
```

包含前端资源的 wheel 安装包可直接运行 `mclaw`，目标设备无需安装 Node.js。Kaihong OS 的 HDC shell 使用 `run mclaw` 加载系统运行环境。

Kaihong OS 4.1（API 11）和 5.0（API 14）通过系统浏览器打开页面。升级后重新运行 `mclaw`，页面会使用当前后台的连接凭据；重复启动继续复用已有后台。

| 命令 | 用途 |
| --- | --- |
| `mclaw` | 启动或连接本机后台，打开网页 |
| `mclaw cli` | 连接同一后台，进入终端界面 |
| `mclaw status` | 查看后台地址与进程状态 |
| `mclaw stop` | 保存进展，等待任务收尾并退出后台 |

重复运行 `mclaw` 会复用同一数据目录的后台。关闭网页或终端窗口后，后台继续运行；终端中的 `/quit` 只退出当前界面。停止后台会同时停止受管任务、调度和消息渠道。

新启动的后台优先使用 `http://127.0.0.1:18031/`；端口被占用或被系统保留时，依次尝试 `18032、18033…`，直到找到可用端口。实际地址会显示在启动提示和 `mclaw status` 中。

首次启动按设置向导配置供应商和模型。已有配置与历史记录会直接加载。

## 对话与任务

在输入框描述需求，按 Enter 发送，Shift+Enter 换行。附件、技能和设备入口位于输入框左下方，模型选择位于右下方，工作区入口位于输入框下方。

- **模型**：按供应商浏览或搜索。中国区、国际区位于同一供应商分组内，具体模型注明区域。
- **附件**：上传文件，或引用本机已有文件；选中的资料随当前任务提交。
- **技能**：可选择多个技能，当前选择显示在输入区。
- **工作区**：选择任务使用的目录。未指定时，后台在任务文件目录中分配独立的会话子目录。
- **设备**：在支持协同的平台选择已配对、在线且 M-Claw 就绪的设备；未指定时，按任务需要选择可协作设备。

任务执行中可以排队下一条消息、补充当前任务或停止执行。暂停后可继续原任务。执行过程可折叠，展开后查看模型返回的思考内容、工具参数与输出；最终答复独立显示。

用户消息和 M-Claw 回复的下方显示日期与时间，按当前浏览器所在时区展示；鼠标停留可查看精确到秒的时间。子代理详情采用同样的显示方式。旧记录没有保存时间时，不补写推测的时间。

主会话任务成功结束时，如果正在前台查看该任务所属会话，直接显示最终回复并自动确认已读，不显示完成横条；之后切到其他页面或刷新也不会补弹。如果正在其他会话、技能页或设置页等页面，页面中上部显示约 520×60 像素的摘要横条。

摘要取最终回复第一行非空文字，清理 Markdown 格式，长内容以省略号显示。点击“查看结果”进入所属会话并定位到这次回复，输入中的草稿会保留。浏览器不在前台，或会话被应用对话框遮挡时，不会仅因该会话被选中而自动确认已读。

同一时间展示一条横条，右侧的 `+N` 表示其余待查看的完成通知。关闭后刷新或重启服务不会重复弹出，未查看结果时侧栏保留未读标记；断线期间完成的任务会在重连后收到。通知仅在前台 Web 窗口显示，已有对话框关闭后再展示；停止、等待授权、失败及子代理或定时任务结束不触发主会话完成横条。升级前的历史完成任务不补弹通知。

后台创建或更新技能后，所属会话会出现一条默认收起的“技能已保存”通知。展开可查看技能名称、实际保存操作和时间；点击“查看技能”进入现有技能详情。通知随会话保存，刷新页面或重启服务后，重新打开原会话仍可回看。

一次后台整理的多次保存会汇总到同一条通知。已保存但仍在整理时显示“后续整理中”；后续失败或中断时保留已保存的结果并说明未完成。检查正常结束且没有保存内容时保持安静。通知自动到达会话，不弹窗打断当前任务。

输入 `/` 可查找新建会话、历史、切换模型、选择技能、队列、停止和继续等操作。终端命令的完整集合见 [命令速查表](16-命令速查表.md)。

## 会话管理

侧栏支持搜索、打开、重命名、导出和删除会话。同一会话同时由一个界面控制；释放控制权后，可从另一个网页或终端接续。

微信、钉钉和定时任务产生的会话带有来源标识。删除会话会移除对应的历史和队列，工作区中的文件仍保留；运行中的任务需先完成收尾。

## 配置与管理

| 页面 | 可用操作 |
| --- | --- |
| 供应商与模型 | 搜索供应商、添加接入、选择 API 区域、修改模型与凭据、刷新模型库 |
| 工具 | 查看基础能力、启停可选工具、修改后端与凭据来源 |
| 技能 | 查看与编辑技能及简短描述、管理启用状态、审核安装内容 |
| 技能市场 | 切换中英文 Trending 榜单、查看技能详情、一键安装 |
| 定时任务 | 创建和调整计划、立即执行、查看运行记录与投递目标 |
| 消息渠道 | 配置、连接和断开微信或钉钉，查看连接状态 |
| 设置 | 调整共享配置、记忆、任务文件目录、语音和服务选项 |

配置沿用 `MCLAW_HOME` 中的 `config.yaml` 和 `.env`。各项设置按页面标注的时机生效，API Key 由后台保存。并发修改发生冲突时，需重新读取后再保存。

## 技能市场

侧栏“技能市场”提供“中文技能市场”和“英文技能市场”两个标签，分别来自 SkillHub 和 skills.sh，榜单标题统一为 Trending，均展示前 40 个技能，顺序沿用来源网站。英文市场展示 24 小时安装量；中文市场展示来源提供的下载量，保留原图标、中文说明和“需要 API Key”“付费”标签。

两个市场采用相同的榜单布局，按来源排名逐条展示 40 个技能。点击技能名称后，从右侧覆盖打开详情，榜单保持原宽度；点击详情外部、关闭按钮或按 Esc 即可关闭。列表中的“安装”按钮可直接安装技能，搜索范围为当前榜单的 40 个技能。

榜单刷新后，两个市场各以 2 个技能并发准备说明和安全报告，分别使用独立队列，并复用网络连接。英文市场按仓库合并安全报告请求，同一来源最多每秒发起 1 次请求；中文市场最多每秒 4 次。刷新榜单会复用仍有效的详情缓存，只补充缺失、过期或版本变化的条目。页脚显示准备进度，列表可以立即浏览。两个市场的详情保存在本地，重启后仍可使用；点击技能优先显示已缓存内容。首次读取尚未准备好的技能时，可能需要等待来源网站响应。源站说明不可用时，页面会显示提示和来源链接。

来源网站返回 429 时，该来源的请求会共同暂停，按照 `Retry-After` 指定的时间继续；未指定时间时从 60 秒开始退避。详情请求最多自动重试一次，另一市场继续加载。页面会显示“来源限流，稍后继续准备”，已有缓存保持可用；手动刷新榜单也会遵守冷却时间。

完整详情每 15 分钟允许更新，读取失败或审核状态未知时每 1 分钟允许重试。缓存过期时先展示已有内容，再后台更新，面板显示获取时间并自动补上更新结果。英文说明和审核信息并行读取，中文说明与审核信息复用详情数据，同一技能的重复加载共用请求。榜单与详情的准备均不调用模型。

首次打开时读取榜单，并记住浏览器的本地时区。后台运行时每天 08:00 自动刷新，也可点击“刷新榜单”立即更新。后台在刷新时间关闭时，下次启动补齐更新；网络暂时不可用时继续展示最近成功缓存的榜单和更新时间。浏览榜单和刷新数据不调用模型。

点击“安装”将技能加入与终端共用的技能目录。安装中会显示进度状态，失败可重试，成功后可在“技能”页查看与管理。同一来源已安装的技能不会重复安装；同名的其他技能保留，页面会说明冲突。需要 API Key 或付费的技能，其服务配置和费用以技能作者说明为准。

英文技能详情与对话中的 skills.sh 安装审核使用相同的第三方报告，显示“综合安全评估”“代码安全检查”“指令风险检查”。这些中文名称分别对应 Gen、Socket、Snyk。

中文技能详情与对话中的 SkillHub 安装审核展示“科恩实验室”“云鼎实验室”的结果，保留来源提供的“安全，无风险”、扫描中或风险提示等状态，可点击报告链接阅读原始结果。安装结果也会附上审核提示。报告来自来源网站，不调用模型；缺失、获取失败或与所选版本不符时显示“暂无报告”，由用户自主选择安装。

## 子代理

主代理分配任务后，执行过程中会显示各子代理的任务名称、状态和最近进展。点击任务可打开详情弹窗，按普通会话的方式查看过程、工具调用和回复；展开工具可查看命令、参数、输出及错误。

弹窗关闭后任务继续执行。阅读较早内容时，新的输出不会把页面拉回底部；点击“回到最新”可继续跟随。执行记录随会话保存，重新打开后仍可查看。旧版记录如果只保存了状态和结果，详情中会注明。

## 设备协同

设备页提供本机信息、附近设备搜索、系统配对和已配对设备管理。跨设备协同仅在具备原生运行环境的 Kaihong OS / M-Robots OS 上开放；Windows 显示平台限制。

跨设备任务需要两端启用协同并完成系统配对。配对成功后，对端 M-Claw 仍需在线并就绪。任务可返回进展、请求补充资料和回传文件，具体权限与使用方法见 [可信设备协作](17-可信设备协作.md)。

两端均支持长回复时，单条远端正文最多可传回 256 KiB；收到并校验完整正文后，本端 M-Claw 继续分析。执行过程中的远端任务可展开查看完整回复。连接旧版设备时沿用 24 KiB 的正文限制，实际生成长度仍取决于模型能力与输出配置。

## 故障排查

- 页面提示缺少前端资源：从源码安装时，重新执行前端构建命令。
- 页面无法连接：运行 `mclaw status` 检查后台，再运行 `mclaw` 打开有效的本机入口。
- 新增供应商：从“供应商与模型”打开独立配置页。
- 目标工具或设备不可用：检查平台支持、工具开关、凭据和设备就绪状态。

会话执行日志位于应用数据目录的 `logs/sessions/`，按会话 ID 的 SHA-256 命名；日志行包含会话和执行 ID，可核对图片准备、模型请求、工具耗时和错误。每个日志文件最多约 4 MiB，保留两份轮转备份。诊断记录凭据脱敏，常规记录仅包含执行阶段和数量，不包含完整对话或图片 Base64。

前端目录、构建检查和打包流程见 [Web UI 开发说明](../../webui/README.md)。
