# 文件、终端与后台进程

## 文件能力

M-Claw 提供文件读取、创建或覆盖、精确修改、删除、内容搜索和目录浏览。任务中应尽量说明目标目录、文件名、预期结果以及是否允许覆盖。

```text
# 读取文件：
读取当前目录的 pyproject.toml，总结项目依赖。
```

```text
# 创建文件：
在 docs 目录创建 deployment.md，写入 Windows 和 Linux 部署步骤。
```

```text
# 搜索内容：
查找项目中所有包含 TODO 的 Python 文件，按文件汇总。
```

文件读取结果受字符上限控制；大文件会按区段读取。精确修改会校验原始文本，避免在内容已变化时错误覆盖。

## 终端执行

终端工具继承当前会话工作目录，并针对 Windows 或 POSIX 选择对应 Shell。它适合运行构建、测试、诊断和版本查询命令。

```text
# 运行测试：
运行项目测试，分析失败原因，但先不要修改代码。
```

```text
# 检查 Git 状态：
检查当前 Git 状态，并说明哪些文件有未提交修改。
```

单次命令有默认超时和最大超时。命令执行后的工作目录变化会同步回会话，后续工具继续使用新的目录。

## 后台进程

需要持续运行的服务可以通过后台进程机制启动。M-Claw 会返回进程标识，并能继续轮询输出、等待完成或终止进程。

```text
# 启动后台服务：
在后台启动本地开发服务器，确认端口可访问，然后告诉我访问地址。
```

中断任务时，运行时会尝试终止对应进程树或进程组，而不仅是停止等待输出。

## 文件安全联动

支持 Checkpoint 的平台会在文件写入、修改、删除以及检测到破坏性终端命令前创建快照。变更完成后可通过 `/rollback` 查看和恢复，详见 [Checkpoint、Rollback 与安全](13-检查点回滚与安全.md)。
