# 微信与钉钉

## 通道设计

通道运行时把微信或钉钉消息映射到 M-Claw Session，并把 Agent 结果发回原会话。通道拥有独立的访问策略、去重、媒体缓存、消息分段、会话范围和中断控制。

本地 CLI Slash Command 与通道命令不是同一套命令。通道未识别的普通消息会进入 Agent；通道本地命令会在进入 Agent 前处理。

## 微信

### 登录

```powershell
mclaw weixin login
mclaw weixin login --bot-type 3
mclaw weixin login --timeout 480
mclaw weixin login --no-qr
mclaw weixin login --connect
```

- `--no-qr`：只打印二维码链接。
- `--connect`：扫码成功后立即启动私聊网关。

### 启动

```powershell
mclaw weixin
```

微信通道当前面向私聊，默认 DM 策略为开放。可以通过配置限制允许用户，并选择按用户维护会话。

### 微信命令

```text
/help       查看通道命令
/new        创建新的微信会话
/stop       中断当前任务
/status     查看当前会话状态
```

微信适配器支持接收媒体、缓存下载内容、分段发送长回复，以及在当前会话发送 Agent 生成的文件。

## 钉钉

### 配置和检查

```powershell
mclaw dingtalk login
mclaw dingtalk check
mclaw dingtalk check --strict
mclaw dingtalk check --json
```

- `--strict`：通道未就绪时返回非零退出码。
- `--json`：输出机器可读诊断报告。

启动 Stream 网关：

```powershell
mclaw dingtalk
```

### 钉钉命令

```text
/help
/new
/stop
/status
```

钉钉支持私聊和群聊。默认群策略为 `mention_only`，通常需要 @ 机器人；可以通过允许用户、允许会话和自由响应会话配置进一步控制。

## Scheduler 目标绑定

在 `/schedule` 的输出方式页面添加通道目标后，M-Claw 会生成短期绑定码和对应命令。例如：

```text
/schedule-bind <绑定码> <备注名>
```

钉钉群中可能需要：

```text
@机器人名称 /schedule-bind <绑定码> 研发群
```

在目标会话发送绑定命令后返回本地任务中心检查状态。绑定成功后建议先执行“测试发送”，再把目标用于正式任务。

## 访问与安全

通道使用各自的 Toolset 配置。文件发送工具只面向当前会话注册，不会允许任意会话之间转发。媒体大小、缓存目录、下载超时和消息长度均可通过配置控制。
