# 快速开始

## 运行要求

- Python 3.11 或更高版本。
- Windows 或 Linux 建议安装 Git；Checkpoint 和 Rollback 会使用独立的 shadow Git 存储。
- 浏览器自动化需要 Playwright Chromium。
- 模型、搜索、视觉、语音和通道功能可能需要对应的 API Key。

## 安装

```powershell
git clone https://gitcode.com/m-robots/mclaw.git
cd mclaw
pip install -e .
```

浏览器自动化依赖：

```powershell
# Windows
python -m playwright install chromium
```

```bash
# Linux
python -m playwright install --with-deps chromium
```

## 首次配置

```powershell
mclaw setup
```

设置向导用于选择 Provider、模型、接口类型和凭据。凭据保存在 M-Claw Home 的 `.env` 中，并通过 scoped secret 机制按功能授权，不会直接加入模型上下文。

完成后运行：

```powershell
mclaw doctor
mclaw
```

Kaihong OS 或 M-Robots OS 使用：

```bash
run mclaw setup
run mclaw
```

## 第一个任务

启动后可以输入一个目标明确、可验证的任务。

```text
# 第一个任务：
检查当前项目结构，说明它的主要模块，并把结果保存为 project-overview.md。
```

M-Claw 会构建运行上下文，调用模型，选择所需工具，执行任务并保存会话。涉及文件写入时，支持 Checkpoint 的平台会先保留可恢复快照。

## 恢复会话

在终端恢复最近会话：

```powershell
mclaw resume
```

按 ID 或前缀恢复：

```powershell
mclaw resume <session_id>
```

进入 M-Claw 后也可以使用：

```text
/history
/resume <会话ID或前缀>
```

## 更新源码版本

先退出正在运行的 M-Claw，然后执行：

```powershell
git status --porcelain
git pull --ff-only
pip install -e .
```

如果 `git status --porcelain` 有输出，应先确认本地修改，避免更新时覆盖自己的工作。
