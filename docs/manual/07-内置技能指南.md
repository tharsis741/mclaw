# 内置 Skill 指南

内置 Skill 会在启动时同步到 M-Claw Skill 存储。实际可用列表以 `/skills` 为准；部分 Skill 需要额外依赖、设备或 API Key。

## 通用使用方式

```text
/<skill-name> <任务描述>
```

如果不确定输入要求，先输入 `/<skill-name>` 加载 Skill，再描述任务。

## 办公与内容

### data-analyzer

用于读取和分析 Excel、CSV、Word、PDF、TXT、Markdown 等格式，生成统计、图表和报告。应提供数据文件位置、关注指标和期望输出。

```text
# 分析数据：
/data-analyzer 分析 sales.xlsx 的月度趋势和异常值，输出中文结论
```

### pptx-generator

用于规划并生成 PowerPoint 演示文稿，包含页面类型和设计规范参考。

```text
# 生成演示文稿：
/pptx-generator 根据 report.md 制作一份 10 页项目汇报 PPT
```

### minimax-docx

用于创建、编辑、分析和校验 DOCX，包含 Open XML、中文排版、样式、批注和修订参考。

```text
# 生成 Word 文档：
/minimax-docx 将 proposal.md 制作成正式中文项目建议书
```

### minimax-xlsx

用于创建、读取、编辑、修复和校验 XLSX，包含公式、样式和 OOXML 工具。

```text
# 编辑 Excel 表格：
/minimax-xlsx 为 budget.xlsx 添加季度汇总并检查公式错误
```

### minimax-pdf

用于 PDF 创建、重排、合并及表单处理。复杂场景可能调用附带脚本。

```text
# 生成 PDF：
/minimax-pdf 将当前目录的三份报告合并，并生成统一封面
```

### khazix-writer

用于按内置内容方法和风格样例完成长文写作。

```text
# 撰写长文：
/khazix-writer 写一篇面向开发者的 M-Claw 技术介绍
```

## 文件与系统

### file-organizer

用于按规则整理文件。执行前应明确目录、分类方式和是否允许移动文件。

```text
# 整理文件：
/file-organizer 分析 Downloads 目录，先给出整理方案，不要立即移动
```

### storage-analyzer

用于 Windows 和 macOS 的只读磁盘扫描，识别空间占用，并把候选项分为可自动清理、需人工判断和谨慎清理三级。它会生成交互式 HTML 报告；真正删除前仍需用户操作。

```text
# 分析存储空间：
/storage-analyzer 分析当前用户目录的空间占用并生成报告
```

### neat-freak

用于在开发阶段结束时核对源码、项目文档和 Agent 记忆，识别过期或冲突知识并完成交接整理。它按照同步矩阵和不同 Agent 的路径规则执行。

### mmx-cli

通过 MiniMax `mmx` CLI 生成文本、图片、视频、语音和音乐，也支持聊天、联网搜索和资源管理。需要安装 `mmx-cli` 并完成 MiniMax API 认证。

## 网络、设计与信息

### weather

用于查询指定地点和时间范围的天气。

```text
# 查询天气：
/weather 查询深圳未来三天天气并给出出行建议
```

### aihot

通过 AI HOT 的公开 REST API 查询中文 AI 日报、精选条目、论文、模型、产品和行业动态，不要求用户配置 API Key。应说明日期范围、分类和输出形式。

### popular-web-designs

提供大量主流产品网站的设计风格参考，可用于网页视觉方向和页面实现。

```text
# 参考网站设计：
/popular-web-designs 参考 Linear 风格设计一个 AI 工具落地页
```

### hv-analysis

使用“横纵分析法”研究产品、公司、概念、技术或人物：纵轴追踪历史演进，横轴比较同期竞品，最终生成排版完整的 PDF 深度研究报告。

## 设备与专业能力

### local-camera

通过本地相机脚本捕获图像，依赖可访问的摄像头设备。

```text
# 使用本地相机：
/local-camera 拍摄一张当前画面并描述其中内容
```

### kaihong-robot-dog

用于连接和控制 Kaihong 机器狗，依赖对应设备、网络和主机客户端。

```text
# 检查机器狗：
/kaihong-robot-dog 检查机器狗连接状态
```

涉及物理动作时，应先确认设备状态、周围环境和动作安全范围。

### arm-cortex-expert

提供 ARM Cortex 相关专业知识和分析能力。

每个 Skill 的精确能力、依赖和限制会随 Skill 内容演进；本页负责入口说明，执行时应以当前安装版本的 `SKILL.md` 为准。
