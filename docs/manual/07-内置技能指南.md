# 内置 Skill 指南

内置 Skill 随 M-Claw 版本发布，在 Setup 的技能选择步骤安装到 M-Claw Skill 存储。当前版本内置 14 个 Skill；实际已安装列表以 `/skills` 为准，部分 Skill 需要额外依赖或 API Key。

每个内置 Skill 的 `mclaw_skill.yaml` 中，`source.original` 记录原始技能地址，`source.author`、`source.license` 和 `source.license_url` 记录作者与许可证信息，目录内附带原始 `LICENSE`。安装时保留这些来源信息，`created_by: bundled` 表示通过内置技能安装。已有内置技能在下次 Setup 同步时补齐来源和缺失的许可证，并保留用户修改的技能正文。

## 通用使用方式

```text
/<skill-name> <任务描述>
```

如果不确定输入要求，先输入 `/<skill-name>` 加载 Skill，再描述任务。也可以直接描述任务，由 M-Claw 根据当前可用的技能自行选择；WebUI 中可以在技能页选择“在对话中使用”。

## 办公与内容

### internal-comms

将工作记录整理成周报、项目进展、管理层汇报、团队简报、内部通知和 FAQ。内置 Anthropic 的四类沟通参考，并适配中文办公场景、会话附件和 M-Claw 文件工具；保留已完成、计划、阻塞等状态差异及材料中的来源。

```text
/internal-comms 根据本次上传的工作记录写本周周报，包含进展、下周计划和需要支持的问题
```

### humanizer-zh（Humanizer-zh）

润色已有中文文字，减少空话、重复和模板化表达，同时保留事实、作者语气、否定与限定条件。保留上游 31 项表达模式及前后示例，按需读取；修改 Markdown 时保护代码、链接、数据和标题结构。

```text
/humanizer-zh 润色当前目录的 proposal.md，保留事实和正式语气，另存为 proposal-edited.md
```

这两项技能使用当前配置的模型，不需要额外应用或专用 API Key。写作默认交付稿件；访问外部办公平台或发送消息需要对应工具及用户指令。处理 Word、PDF 等文件时使用当前可用的文档工具或已安装的对应技能。

### pptx-generator

用于规划并生成 PowerPoint 演示文稿，包含页面类型和设计规范参考。

```text
# 生成演示文稿：
/pptx-generator 根据 report.md 制作一份 10 页项目汇报 PPT
```

### minimax-docx

用于创建、编辑、分析和校验 DOCX，包含 Open XML、中文排版、样式、批注和修订参考。

```text
# 生成 Word 文档：
/minimax-docx 将 proposal.md 制作成正式中文项目建议书
```

### minimax-xlsx

用于创建、读取、编辑、修复和校验 XLSX，包含公式、样式和 OOXML 工具。

```text
# 编辑 Excel 表格：
/minimax-xlsx 为 budget.xlsx 添加季度汇总并检查公式错误
```

### minimax-pdf

用于 PDF 创建、重排、合并及表单处理。复杂场景可能调用附带脚本。

```text
# 生成 PDF：
/minimax-pdf 将当前目录的三份报告合并，并生成统一封面
```

### khazix-writer

用于按内置内容方法和风格样例完成长文写作。

```text
# 撰写长文：
/khazix-writer 写一篇面向开发者的 M-Claw 技术介绍
```

## 开发与媒体

### neat-freak

用于在开发阶段结束时核对源码、项目文档和 Agent 记忆，识别过期或冲突知识并完成交接整理。它按照同步矩阵和不同 Agent 的路径规则执行。

### mmx-cli

通过 MiniMax `mmx` CLI 生成文本、图片、视频、语音和音乐，也支持聊天、联网搜索和资源管理。需要安装 `mmx-cli` 并完成 MiniMax API 认证。

## 前端设计

### design-taste-frontend（Taste Skill）

用于创建有鲜明视觉风格的官网、落地页、产品展示和个人作品集。当前内置 Taste Skill 2.0.0，包含构图、字体、配色等设计资料及素材检索、源码检查、浏览器检查脚本。

```text
/design-taste-frontend 为一家深圳咖啡店制作有辨识度的中文官网
```

脚本需要 Node.js 22+，浏览器检查需要 Chrome、Edge 或 Chromium；可通过 `CHROME_PATH` 指定浏览器路径。素材检索需要联网，不需要额外 API Key，下载素材仍需保留各自的许可与署名。设计工作文件保存在用户项目的 `.taste-skill/` 中。

技能保留上游的适用范围和工作流程，由 M-Claw 根据任务自行选择，也可以通过技能名称直接指定。

## 网络与信息

### knowledge-synthesis

综合多份本地文档、网页和检索结果，按问题去重、交叉核对、解释冲突并给出带来源的结论。保留原始材料的日期、版本和适用范围，区分正式决定、讨论方案与推断；转载同一资料不计为独立验证。

```text
/knowledge-synthesis 对比上传的三份方案，整理共同结论、分歧和待核实项，并标明每项依据
```

综合已有材料不需要额外应用或专用 API Key。任务需要联网时使用 M-Claw 已配置的 `web_search` 和 `web_extract`，其可用性与凭据由对应工具设置决定。结果可直接在对话中返回，或按要求保存到当前会话工作目录；正式文档可以接续使用已安装的文档技能生成。

### weather

用于查询指定地点和时间范围的天气。

```text
# 查询天气：
/weather 查询深圳未来三天天气并给出出行建议
```

### aihot

通过 AI HOT 的公开 REST API 查询中文 AI 日报、精选条目、论文、模型、产品和行业动态，不要求用户配置 API Key。应说明日期范围、分类和输出形式。

### hv-analysis

使用“横纵分析法”研究产品、公司、概念、技术或人物：纵轴追踪历史演进，横轴比较同期竞品，最终生成排版完整的 PDF 深度研究报告。

每个 Skill 的精确能力、依赖和限制会随 Skill 内容演进；本页负责入口说明，执行时应以当前安装版本的 `SKILL.md` 为准。

版本升级会保留用户已经安装的技能及本地修改；移出内置清单的技能不会因此从用户技能目录删除。
