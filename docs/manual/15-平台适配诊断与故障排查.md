# 平台适配、诊断与故障排查

## Runtime 适配

M-Claw 启动时识别操作系统和运行环境：

- Windows 使用 `WindowsRuntime`。
- Linux 使用 `LinuxRuntime`。
- M-Robots OS/Kaihong OS 使用 `KaihongRuntime`。

Runtime 负责 Shell、进程、路径、环境变量和功能状态。工具定义会根据平台能力、依赖、配置和凭据动态过滤。

## 能力矩阵

| 功能 | Windows | Linux | Kaihong/M-Robots OS |
| --- | --- | --- | --- |
| Agent CLI | 支持 | 支持 | 支持 |
| 文件与终端 | 支持 | 支持 | 支持 |
| Checkpoint | 支持，需 Git | 支持，需 Git | 按 Git 与配置状态 |
| 浏览器自动化 | 支持，需依赖 | 支持，需依赖 | 按依赖与运行环境 |
| 桌面宠物 | 支持，需依赖 | 需依赖与图形环境 | 按依赖与显示环境 |
| 语音 | `sounddevice` | `sounddevice`/`arecord` | `arecord` |
| 微信/钉钉 | 按配置 | 按配置 | 按配置与依赖 |
| 可信设备协作 | — | — | 支持，需 DSoftBus 环境与用户启用 |

## 诊断命令

启动前：

```powershell
mclaw doctor
```

M-Robots OS/Kaihong OS 的 M-Terminal 使用：

```bash
run mclaw doctor
```

运行中：

```text
/doctor
```

诊断覆盖核心 Runtime、Provider、工具集、环境变量、浏览器、语音、通道和可信设备协作状态。可选工具显示未配置时，不影响基础 Agent 启动。

## 常见问题

### 模型不可用

1. 运行 `/provider` 检查 Provider 和密钥。
2. 运行 `/model-update provider <供应商> profile` 检查接口类型。
3. 确认模型名、Endpoint 和协议匹配。
4. 重新运行 `mclaw setup`。

### 浏览器工具不可用

在安装 M-Claw 的同一个 Python 环境运行：

```powershell
python -m playwright install chromium
```

随后运行 `/doctor`。M-Robots OS/Kaihong OS 上的实际可用性以 Runtime 对依赖和运行环境的诊断结果为准。

### 搜索或提取后端不可用

使用 `/search-backend` 或 `/extract-backend` 查看状态。切换云端后端时按提示授权对应 API Key。本地 Trafilatura 不需要云端密钥。

### ASR 无法启动

运行 `/asr-status`，检查 DashScope 凭据、麦克风权限和录音设备。Linux/Kaihong 上同时检查 `arecord` 和 ALSA 设备占用。

### Checkpoint 不可用

确认平台支持、Git 已安装且配置中 `checkpoints.enabled` 为 true。M-Robots OS/Kaihong OS 产品镜像未提供 Git 时，该功能会显示不可用。

### 可信设备协作不可用

1. 确认当前系统是受支持的 M-Robots OS/Kaihong OS，并已在 Setup 中启用“可信设备协作”。
2. 在两端分别运行 M-Claw，并使用 `/devices` 查看 Agent 状态。
3. 启动后 Runtime 仍在初始化时，等待数秒并重新执行 `/devices`。
4. 已完成系统配对但显示“Agent 未就绪”或“正在重连”时，检查对端 M-Claw、WLAN 数据通道和系统时间。
5. `/pair` 超时时，检查被连接端的系统配对确认和 PIN 流程。
6. 运行 `/doctor`，并根据 DSoftBus Runtime、Worker 和设备发现诊断继续处理。

完整操作流程见[可信设备协作](17-可信设备协作.md)。

### 微信或钉钉无法连接

- 微信重新运行 `mclaw weixin login`。
- 钉钉运行 `mclaw dingtalk check --strict`。
- 检查是否已有同一通道实例持有运行锁。
- 检查网络、凭据和允许用户/会话策略。

### Scheduler 没有执行

确认承载 Scheduler 的 M-Claw 进程仍在运行，任务处于 enabled，目标未停用，并查看运行记录。默认轮询间隔为 30 秒，不保证精确到秒触发。
