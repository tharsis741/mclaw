# 搜索、网页、浏览器与视觉

## 联网搜索

联网搜索用于从互联网检索信息并返回来源。后端支持 DashScope、Tavily 和自动选择。

```text
/search-backend
/search-backend auto
/search-backend dashscope
/search-backend tavily
```

切换到需要凭据但尚未授权的后端时，M-Claw 会进入密钥配置流程。

```text
# 联网搜索：
搜索最近一周具身智能领域的重要新闻，按时间排序并附来源。
```

## 网页正文提取

网页提取用于已知 URL 的正文读取，后端包括本地 Trafilatura、Tavily 和 Firecrawl。

```text
/extract-backend
/extract-backend trafilatura
/extract-backend tavily
/extract-backend firecrawl
```

Trafilatura 是默认本地提取方式；Tavily 和 Firecrawl 需要相应凭据。

```text
# 提取网页正文：
读取这个页面，整理主要观点和数据：https://example.com/article
```

## 浏览器自动化

浏览器运行时提供 16 个工具。同一会话的标签页共享浏览器上下文，不同会话使用独立上下文。Web 与 TUI 共用这套后端。

| 能力 | 工具与用法 |
| --- | --- |
| 页面与快照 | `browser_navigate(url)` 打开页面并返回快照；`browser_snapshot(offset)` 刷新快照或继续查看剩余控件；`browser_back()` 后退。 |
| 基础交互 | `browser_click(ref)`、`browser_type(ref, text)`、`browser_scroll(direction, ref)`、`browser_press(key)`、`browser_hover(ref)`。滚动时可指定区域内的 ref，定位 iframe 或 Shadow DOM 内的滚动容器。 |
| 表单 | `browser_select(ref, values)` 按 option 的 value 选择原生下拉选项；`browser_check(ref, checked)` 设置勾选状态。自定义下拉组件使用点击和按键。 |
| 标签页 | `browser_tabs(action, tab_id, offset)` 支持 `list`、`new`、`select`、`close`。新建后用 navigate 打开 URL；页面打开的弹出标签页会列出，需显式切换。list 每次返回最多 20 个标签页，可用返回的 next_offset 继续查看。 |
| 文件 | `browser_upload(files, ref)` 选择本地文件；`browser_download(url, path, ref)` 下载文件。上传可省略 ref，使用上次点击打开的文件选择器；空 files 列表清除选择。 |
| 弹窗 | **先**调用 `browser_handle_dialog(accept, prompt_text)`，**再**触发 alert、confirm 或 prompt；响应在当前标签页下一次操作中使用一次，操作结束或超过 60 秒即失效。未设置的弹窗默认关闭，结果随快照返回。 |
| 等待 | `browser_wait_for(text 或 ref, state, timeout_ms)` 等待出现或消失。text 与 ref 二选一，state 为 `visible` 或 `hidden`，默认等待 10 秒，上限 30 秒，可取消。 |
| 截图 | `browser_screenshot(path, full_page)` 默认保存完整页面 PNG；`full_page=false` 截取视口，`.jpg` 路径保存 JPEG。默认文件名唯一，返回路径、大小和 MIME 类型。 |

快照覆盖当前视口、可见 iframe 和开放的 Shadow DOM，包含可见文字、元素标签、禁用状态、勾选状态及下拉选项；密码输入值不输出。原生模态对话框打开时，快照聚焦当前对话框，排除背景和 `inert` 区域；支持空值、`true` 和 `plaintext-only` 的可编辑输入区。每次最多检查前 32 个 frame，控件和文字输出受长度限制。如果返回 `next_offset`，将它作为下一次 `browser_snapshot` 的 `offset`，可继续查看同一视口的剩余控件；页面变化后从 offset=0 重新观察。视口外的内容用滚动查看。封闭的 Shadow DOM、画布内部控件仍需其他交互方式。

**每次新快照都会替换此前的元素引用。** 导航与交互通常已返回新快照，可直接使用其中的 ref。工具按真实 DOM 节点绑定引用；旧 ref 或已被替换的节点返回 `STALE_REF`，不会改为点击另一个元素。列出标签页和设置弹窗响应不会刷新引用。

结果包含 `success` 与错误原因。`SNAPSHOT_FAILED` 表示观察失败；若同时返回 `action_completed=true`，说明交互已执行，应刷新快照确认结果，避免重复提交。`completion_unknown=true` 表示操作结果尚不能确定；`WAIT_TIMEOUT` 表示指定条件未在时限内满足。`BROWSER_TIMEOUT` 表示整个调用超过时限，已发起清理；普通调用上限 45 秒，包含排队时间，显式等待额外预留 5 秒用于观察。超时和用户主动取消分开报告。

浏览器断开或上下文失效后，下次调用会重新建立会话，并在快照中返回 `session_reset=true`。原标签页及登录状态可能丢失，失败的交互不会自动重放。所有会话目前共用一个浏览器进程和工作线程；普通取消只关闭对应会话，底层连接无法恢复时会重置共享浏览器，并报告受影响会话的重置状态。

上传、下载和截图路径遵循 Runtime PathPolicy；相对路径按会话工作目录解析，下载还会检查服务器建议的最终文件名。下载持续捕获，包括延迟触发、按键触发和弹出标签页中的下载。保存失败且返回 `download_retained=true` 时，只传新 path 重试即可，不必再次点击；捕获信息保留至会话关闭。截图和下载先写临时文件，成功后才写入目标位置。选择文件可能立即触发网站上传。截图返回文件，可交给图片理解工具进一步分析。

直接传入 HTTP/HTTPS 下载地址时，会沿用当前浏览器会话的 Cookie，在临时标签页保存文件，当前标签页及其元素引用保持可用。可直接显示的图片、PDF、文本也可下载；服务器文件名和重定向会保留，HTTP 错误不会作为文件保存。页面生成的下载使用 ref 触发。实现使用 Chromium 的[响应头处理接口](https://github.com/ChromeDevTools/devtools-protocol/blob/master/pdl/domains/Fetch.pdl)，文件内容由浏览器下载。

```text
# 网页交互与下载：
打开指定网站，进入下载页面，下载最新版本的发布说明。
```

```text
# 网页截图：
打开这个页面并截取完整页面，保存到当前目录。
```

浏览器依赖 Playwright Chromium 和可用的运行环境。可以使用 `/doctor` 检查；诊断按当前 Playwright 驱动要求的版本和可执行文件判断，支持 headless-only 安装及 `PLAYWRIGHT_BROWSERS_PATH=0`。可执行文件存在不代表系统运行库齐全，实际启动结果仍需确认；M-Robots OS/Kaihong OS 是否可用由本机依赖和 Runtime 诊断结果决定。

升级兼容：如果旧配置禁用了原有的全部 8 个浏览器工具，新增工具也保持关闭；在工具设置中重新启用浏览器后，整组生效。读取旧配置时不改写配置文件。

本次浏览器回归环境：Windows 11（10.0.26200）、Python 3.12.8、Playwright 1.58.0、Chromium 145.0.7632.6。交互使用本地测试页面和真实 Chromium 验证；Kaihong OS/M-Robots OS 的检查属于 Runtime 模拟测试，尚未进行目标设备实测。

## 图片理解

视觉工具使用配置的 Qwen 视觉模型分析本地图片或图片 URL，可用于场景理解、OCR、界面检查和设备状态识别。

```text
# 分析设备图片：
分析 C:\images\panel.jpg，识别面板上的文字和告警灯状态。
```

```text
# 分析界面截图：
检查这张界面截图，指出可能影响使用的布局问题。
```

本地路径仍受 PathPolicy 约束。图片过大时，处理层会转换或压缩到模型可接受的输入。
