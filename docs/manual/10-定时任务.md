# Scheduler 定时任务

## 功能设计

Scheduler 把一次性的 Agent 任务转化为可持续调度的任务。每个任务包含：

- 调度规则与时区
- 任务名称和提示词
- 最大迭代次数与超时
- 输出文件规则
- 本地、微信或钉钉投递目标
- 下次执行时间和启用状态

触发后，Scheduler 创建独立运行记录，执行 Agent，保存工具调用、Token 用量、结果、错误和输出路径，再进行投递。运行中的任务可被取消，异常退出后会处理过期的运行记录。

## 打开任务中心

```text
/schedule
```

`/schedule` 是交互式任务中心，不使用虚构的 `add`、`delete` 等命令参数。进入后根据当前页面底部的操作区输入编号或字母。

主页面包括：

```text
1 新建定时任务
2 查看定时任务
3 立即运行
4 暂停/恢复
5 投递目标
6 运行记录
7 删除任务
B 返回聊天
```

任务超过 10 个时还会显示下一页和上一页。界面实际可用项会根据当前任务和目标状态变化。

## 创建任务

### 1. 选择输出方式

可以保存到内置本地输出、选择已有目标，或添加微信/钉钉目标。通道目标需要完成绑定，详见 [微信与钉钉](11-微信与钉钉.md)。

### 2. 选择调度类型

| 类型 | 输入格式 | 示例 |
| --- | --- | --- |
| 每日 | `HH:MM` | `09:00` |
| 每周 | `Weekday HH:MM` | `Monday 09:00` |
| 每月 | `day HH:MM` | `1 09:00` |
| 固定间隔 | 数字加单位 | `30s`、`30m`、`2h`、`1d` |
| 单次 | `YYYY-MM-DD HH:MM` | `2026-08-10 09:00` |
| Cron | 五段式表达式 | `0 9 * * 1-5` |

输入时间后会预览后续三次执行时间。默认时区为 `Asia/Shanghai`。

### 3. 填写任务

任务名称用于列表识别；任务内容是每次触发时交给 Agent 的完整提示词。提示词应包含数据来源、处理目标、输出格式和失败条件。

```text
# 定时任务提示词：
搜索过去 24 小时具身智能行业新闻，去重后选择最重要的 10 条，
为每条生成中文摘要并保留来源链接，最后给出趋势判断。
```

### 4. 配置本地输出

选择本地输出时可以配置输出目录和文件名模板。运行记录会保存最终路径；历史输出不会因删除任务而自动删除。

### 5. 预览并创建

预览页面会显示名称、调度、下次运行、任务内容、输出目标和执行限制。确认后保存。创建完成页面可以立即试跑一次。

向导中通常使用：

```text
B 返回上一步
C 取消创建并丢弃草稿
```

## 查看与管理任务

任务列表可以进入详情页，查看时间、下次执行、状态、提示词和投递目标。详情页提供立即运行、暂停或恢复、运行记录和删除。

删除任务只删除调度定义，已有运行输出仍保留在本地输出目录。

## 运行记录

运行记录可以按全部任务或单个任务查看，记录包括：

- 计划时间和实际开始时间
- `running`、`succeeded`、`failed` 等状态
- Agent 最终结果和错误
- Token 用量与工具调用
- 投递结果
- 本地输出路径

## 输出目标

输出方式页面可以：

- 查看本地和通道目标
- 添加微信或钉钉目标
- 测试发送
- 修改备注名
- 启用或停用目标
- 删除非内置目标

内置本地输出目标不能改名、停用或删除。删除仍被任务引用的通道目标会使后续投递失败。

## 运行条件

Scheduler Engine 随 M-Claw 运行时启动并按配置轮询到期任务。默认配置为每 30 秒检查一次、每次最多取 5 个到期任务、最多 2 个工作线程。关闭承载 Scheduler 的 M-Claw 进程后不会继续执行；重新启动后 Engine 会根据持久化状态继续调度。

默认单次任务超时 3600 秒、最大迭代 200 次、最大连续失败 5 次。这些属于配置项，当前任务中心不提供逐任务的自由参数编辑界面。
