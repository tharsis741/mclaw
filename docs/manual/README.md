## 三类操作入口

| 入口 | 使用位置 | 示例 |
| --- | --- | --- |
| 启动命令 | 操作系统终端 | `mclaw setup`、`mclaw doctor` |
| Slash Command | M-Claw 本地交互界面 | `/model`、`/schedule`、`/devices` |
| IM通道命令 | 微信或钉钉会话 | `/new`、`/stop` |

除管理命令外，用户可以直接描述目标。M-Claw 会根据当前平台、已启用工具、Skill 和凭据状态规划执行步骤。

## 文档约定

- `<名称>` 表示必填值，输入时不包含尖括号。
- `[参数]` 表示可选值。
- 命令和参数以当前 1.1.1 源码为准。
- 功能是否可用以 `/doctor` 的实际诊断结果为准。
