# 模型与 Provider

## 功能设计

M-Claw 将模型名称、Provider、接口 Profile、Endpoint 和凭据分别管理。当前支持 OpenAI-compatible 与 Anthropic Messages 两类传输协议，并可使用 models.dev 缓存获取模型目录和上下文元数据。

模型切换会同步更新当前运行上下文。恢复历史会话时，M-Claw 会尝试恢复该会话保存的模型与 Provider 配置。

## 查看和切换模型

查看当前模型：

```text
/model
```

切换当前会话模型：

```text
/model <模型名> --provider <供应商>
```

指定接口 Profile：

```text
/model <模型名> --provider <供应商> --profile <接口>
```

保存为全局默认值：

```text
/model <模型名> --provider <供应商> --global
```

未指定模型时，命令会提示正确用法。参数中包含空格时可以使用引号；未闭合的引号会被拒绝。

## Provider 状态

```text
/provider
/provider <供应商> --profile
/provider --profile
```

`/provider` 显示内置和自定义接入方、默认模型及密钥状态。带 `--profile` 时查看接口 Profile；指定供应商可以缩小范围。

## 模型库缓存

```text
/model-update
/model-update status
/model-update provider <接入方>
/model-update provider <接入方> profile
/model-update list [关键词]
```

- 无参数或 `status`：查看缓存路径、Provider 数和模型数。
- `provider`：查看某个接入方的模型映射。
- `provider ... profile`：查看接入方的接口 Profile 和模型列表。
- `list`：搜索 models.dev Provider ID；不带关键词时显示前 20 项。

## 自定义兼容接口

私有部署、代理网关或未收录的模型可以通过 `mclaw setup` 配置自定义 Endpoint。配置时需要明确接口协议、Base URL、模型名和密钥。实际工具调用、视觉输入、流式输出和推理参数能力仍取决于目标模型与 Endpoint。

## 用量

```text
/usage
```

该命令显示当前会话累计的输入、输出、缓存及总 Token 用量。上下文接近预算时，运行时可根据配置压缩较早历史，保留任务状态和关键事实。
