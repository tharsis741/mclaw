# 会话、历史与记忆

## 会话管理

每次对话都会保存会话、消息、工具调用、模型配置、Token 用量和标题。历史数据支持 SQLite FTS5 检索。

```text
/history
/resume <会话ID或前缀>
/title
/title <名称>
/save
/clear
```

- `/history`：显示历史会话。
- `/resume`：加载会话消息，并恢复其模型运行上下文。
- `/title`：无参数时查看标题，带参数时设置当前会话标题。
- `/save`：把当前会话导出为 JSON。
- `/clear`：创建新会话，不删除已有历史。

终端启动时也可以使用 `mclaw resume [session_id]`。

## 历史检索

Agent 可以根据当前任务搜索历史会话，召回以前的讨论、决策和任务结果。检索过程与 `/history` 不同：`/history` 面向用户展示会话列表，历史检索工具面向 Agent 返回相关片段。

```text
# 检索历史会话：
找到我们上次讨论 Scheduler 投递方式的会话，并总结结论。
```

## 三层记忆

### 会话记忆

保存当前和历史会话的完整运行记录，用于继续任务、审计工具调用和统计用量。

### 长期记忆

保存跨会话稳定事实、用户偏好、环境约定和排障经验。长期记忆与用户画像分别维护，并在写入前检查提示注入和敏感信息风险。

```text
# 添加长期记忆：
记住：这个项目的默认 Python 版本是 3.11。
```

```text
# 修改长期记忆：
把我关于报告格式的偏好改成“先结论，后证据”。
```

```text
# 删除长期记忆：
删除关于测试服务器地址的长期记忆。
```

### Skill 记忆

Skill 的运行经验保存在 `skill_evolution.json`，用于记录适配情况、偏好、失败案例和执行注意事项。

## 后台记忆审查

运行时按配置的对话轮次触发后台审查，判断当前会话是否出现值得沉淀的稳定信息。审查任务使用受限工具，不会把所有聊天内容无条件写入长期记忆。
