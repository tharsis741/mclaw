# 交互界面与基础命令

## Agent 执行循环

M-Claw 会将平台信息、已启用工具、Skill 索引、会话历史和长期记忆组合成运行上下文。模型可以连续调用工具，直到得到最终结果、被用户中断，或遇到需要用户处理的阻塞。

工具调用过程会在界面中展示。文件读取等独立操作可以并发执行；写操作会进入安全和 Checkpoint 流程。

## 基础命令

```text
/help                 显示命令中心
/clear                清屏并创建新会话
/usage                查看当前会话 Token 用量
/doctor               检查运行环境和工具状态
/quit                 退出 M-Claw
```

`/clear` 不会删除历史会话，只会创建新的会话上下文。

## 输入与快捷键

| 操作 | 快捷键 |
| --- | --- |
| 发送 | `Enter` |
| 换行 | `Shift+Enter` |
| 中断当前任务 | `Ctrl+C` |
| 退出 | `Ctrl+D` |
| 清空当前输入 | `Ctrl+U` |
| 命令补全 | `Tab` |
| 历史、光标或补全导航 | `Up` / `Down` |
| 接受历史建议 | `Right` |

输入 `/` 后会出现最多四行补全菜单。内置命令拥有命名优先权；如果某个 Skill 与内置命令同名，该 Skill 不会注册为对应 Slash Command。

## 中断行为

`Ctrl+C` 会向当前 Agent 回合、工具、浏览器、网络请求、后台进程或子代理传播取消信号。取消后 M-Claw 会等待相关工作结束并维护会话状态，避免把仍在运行的任务误报为已经停止。

## 工作区信任

首次在某个工作目录执行可能修改文件的任务时，M-Claw 会要求确认工作区风险。确认结果保存在配置中。工作区信任不等于系统沙箱：工具仍使用当前操作系统用户的权限运行。

## 凭据输入

功能需要凭据时，M-Claw 会显示密钥名称和用途，并进入专用输入流程。输入内容不会作为普通聊天消息发送给模型。可输入 `/cancel` 取消当次密钥配置。
