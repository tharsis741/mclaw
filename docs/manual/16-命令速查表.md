# 命令速查表

## 终端命令

| 命令 | 作用 |
| --- | --- |
| `mclaw` | 启动本地 Agent Runtime |
| `mclaw setup` | 初始配置向导 |
| `mclaw doctor` | 运行环境诊断 |
| `mclaw help` | 显示终端命令帮助 |
| `mclaw resume [id]` | 恢复最近或指定会话 |
| `mclaw weixin login [选项]` | 微信扫码登录 |
| `mclaw weixin` | 启动微信网关 |
| `mclaw dingtalk login` | 配置钉钉凭据 |
| `mclaw dingtalk check [--strict] [--json]` | 检查钉钉配置 |
| `mclaw dingtalk` | 启动钉钉网关 |

## 本地 Slash Command

| 命令 | 作用 |
| --- | --- |
| `/help` | 命令中心 |
| `/clear` | 新建会话 |
| `/model` | 查看或切换模型 |
| `/model-update` | 模型库缓存 |
| `/provider` | Provider 与 Profile 状态 |
| `/search-backend` | 搜索后端 |
| `/extract-backend` | 网页提取后端 |
| `/asr-mode` | 开启语音输入 |
| `/asr-status` | ASR 状态 |
| `/keyboard-mode` | 切回键盘 |
| `/pet` | 桌面宠物 |
| `/usage` | 会话 Token 用量 |
| `/doctor` | 运行时诊断 |
| `/history` | 历史会话 |
| `/resume <id>` | 恢复会话 |
| `/rollback` | 撤销文件变更 |
| `/checkpoints` | Checkpoint 管理 |
| `/title [名称]` | 查看或设置标题 |
| `/save` | 导出当前会话 |
| `/schedule` | 本地任务中心 |
| `/skills` | 已启用 Skill |
| `/skill install <source>` | 从 skills.sh、GitHub、ClawHub 或本地目录安装 Skill |
| `/skill creation <brief>` | 创建 Skill |
| `/quit` | 退出 |

Rollback 的 `recover`、`restore`、`turn`、`diff`、`ops` 和 `project` 等高级子命令见 [Checkpoint、Rollback 与安全](13-检查点回滚与安全.md)。

外部 Skill 搜索没有独立 Slash Command。向 M-Claw 提出查找或推荐外部 Skill 的需求后，Agent 会搜索 skills.sh、展示候选，并在用户选择后进入 `/skill install` 的安全确认流程。详见 [Skill 系统](06-技能系统.md)。

## 动态 Skill 命令

```text
/<skill-name>
/<skill-name> <任务描述>
```

## 通道命令

微信和钉钉均支持：

```text
/help
/new
/stop
/status
```

Scheduler 目标绑定：

```text
/schedule-bind <绑定码> <备注名>
```

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Enter` | 发送 |
| `Shift+Enter` | 换行 |
| `Ctrl+C` | 中断 |
| `Ctrl+D` | 退出 |
| `Ctrl+U` | 清空输入 |
| `Tab` | 接受命令补全 |
| `Right` | 接受历史建议 |
| `Up/Down` | 导航历史、光标或补全 |
