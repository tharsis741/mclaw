# file-organizer

按文件名关键词/模式自动分类整理文件夹内的文件。交互式预览 + 一键执行 + 可撤销安全机制。

## 适用场景

- 下载目录（Downloads）堆积了各种格式文件，需要按用途归类
- 桌面文件太多需要整理
- 项目输出目录（编译产物、截图、日志）需要按类别归档
- 任何"文件散落一地需按关键词归类"的场景

## 核心流程

1. 用户指定目标目录
2. 扫描目录内所有文件（递归或仅顶层，由配置决定）
3. 根据硬编码的分类规则（关键词/模式匹配）匹配每个文件
4. 显示预览：展示每个文件将被移动到哪个分类文件夹
5. 用户确认（y/N）后执行移动操作
6. 自动生成撤销脚本（undo_YYYYMMDD_HHMMSS.bat / .sh），可一键恢复

## 输入要求

- 用户提供目标目录路径（绝对路径或相对路径）
- 交互式确认：在移动前必须等待用户输入 `y` 确认

## 资源文件使用方式

- `scripts/organizer.py` — 核心整理脚本，通过 `python scripts/organizer.py <目录路径>` 调用
- 该脚本可直接运行，不依赖外部配置文件

## 分类规则（硬编码在脚本中）

默认分类规则按关键词匹配文件名（不区分大小写）：

| 目标分类文件夹 | 匹配关键词 |
|---|---|
| 图片 | photo, pic, img, 截图, 图片, jpg, png, gif, bmp, webp |
| 文档 | doc, 文档, 报告, report, 简历, 合同, pdf, word, excel, ppt |
| 视频 | video, 视频, 录像, 录制, mp4, avi, mov, mkv |
| 音频 | audio, 音乐, 歌曲, music, mp3, wav, flac, aac |
| 代码 | code, src, 源码, 项目, py, js, ts, html, css, go, rs, java, cpp |
| 压缩包 | zip, rar, 7z, tar, gz, bz2, 压缩 |
| 数据 | data, 数据, 备份, backup, export, csv, json, xml, sql |
| 安装包 | setup, install, 安装, exe, msi, dmg, appimage |

不在任何规则中的文件会被归入 `其他` 分类。

Archive extensions have higher priority than filename keywords: `project.zip` and `code.7z` must go to `压缩包`, not `代码`.

**用户如需自定义规则**，直接修改 `scripts/organizer.py` 顶部的 `RULES` 字典即可。

## 输出规范

1. **预览输出**：表格形式展示"文件名 → 目标分类文件夹"，并统计各类别文件数
2. **实际执行**：将文件移动至目标目录下的 `_整理_分类名/` 文件夹
3. **撤销脚本**：在目标目录生成 `_整理撤销脚本/undo_时间戳.bat`（Windows）或 `.sh`（其他系统）
4. **执行日志**：同时生成 `_整理撤销脚本/undo_时间戳.log` 记录操作详情

## 安全边界

- **预览模式是默认入口**：必须先展示预览，用户输入 `y` 后才执行
- **不递归处理子目录**（默认只处理目标目录的顶层文件），避免误伤已有结构
- **不覆盖已有文件**：如果目标路径已存在同名文件，自动重命名（加数字后缀）
- **撤销脚本保留所有原始路径信息**，可完整恢复
- **生成的操作记录日志**不可删除（撤销需要依赖它）

## 验证方式

1. 准备一个测试目录，放入几个匹配不同规则的测试文件
2. 运行 `python scripts/organizer.py <测试目录>`
3. 确认预览正确显示分类; include `project.zip`, expected `_整理_压缩包/`
4. 输入 `y` 执行
5. 检查文件是否已正确移动到对应分类文件夹
6. 检查撤销脚本是否生成
7. 运行撤销脚本确认文件能恢复原状
